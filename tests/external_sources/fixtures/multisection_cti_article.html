Going with the Flow(s): Distinct Sanitized Clusters

August 20, 2026

Written by: Avery Analyst, Riley Researcher

Overview

Researchers identified three independent intrusion clusters abusing legitimate authentication workflows against selected organizations. This sanitized overview establishes the campaign scope and defensive relevance before the detailed technical sections.

The clusters used targeted phishing, OAuth consent prompts, and carefully staged malware delivery. Defenders should correlate identity telemetry with endpoint and network observations rather than treating each signal independently.

Cluster Alpha

Cluster Alpha used a legitimate device authorization flow and instructed targets to provide a verification value. The activity was bounded, selective, and supported by infrastructure created shortly before each operation.

OAuth activity

Investigators observed consent requests followed by access from unfamiliar infrastructure. Review of cloud audit logs revealed token use that was inconsistent with the affected users' ordinary access patterns.

Cluster Bravo

Cluster Bravo delivered a sanitized malware family named RIVERSTONE. The sample contacted command-and-control infrastructure after collecting basic host metadata and browser configuration information.

The SHA-256 sample identifier was 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef and the observed C2 address was 198.51.100[.]42:8443.

Cluster Charlie

After authenticating, a target was redirected to an attacker-controlled application that attempted to collect an authorization token. Analysts disabled the project and documented the associated infrastructure.

Additional investigation connected the operation to a fake document-sharing service and a downloader named HEADWIND. These details remain sanitized and cannot be used as an operational payload.
